# AI Workflow

Este documento explica como a IA foi usada no desenvolvimento deste portfólio e quais decisões continuaram humanas. A ideia é mostrar um uso profissional de IA: rápido, prático, revisado e responsável.

## Planejamento

A IA foi usada para organizar o objetivo do site, transformar o contexto profissional em seções claras e definir uma estrutura adequada para recrutadores.

Decisão humana:

- Posicionar o portfólio para vagas de Desenvolvedor Júnior / AI Automation Builder.
- Manter o site simples, direto e sem complexidade desnecessária.
- Priorizar empregabilidade, clareza e confiança.

## Estruturação

A IA ajudou a transformar requisitos em uma landing page única com seções bem separadas:

- Hero.
- Sobre mim.
- Método AI-first.
- Projetos.
- O que posso fazer hoje.
- Skills.
- Oportunidades que busco.
- Contato.

Decisão humana:

- Preservar uma arquitetura simples.
- Evitar dependências novas.
- Usar componentes pequenos somente onde fizessem sentido.

## Copy

A IA foi usada para melhorar os textos do site, deixando a comunicação mais direta para recrutadores e empresas.

O foco da copy foi comunicar:

- Perfil júnior em evolução.
- Mais de 200 horas práticas.
- Uso de IA em planejamento, arquitetura, código, debugging, testes e documentação.
- Capacidade de aprender e se adaptar.
- Abertura para CLT, PJ, remoto ou híbrido.

Decisão humana:

- Evitar frases genéricas como "apaixonado por tecnologia".
- Evitar posicionamento de sênior.
- Mostrar IA como ferramenta de produtividade, não como substituta do raciocínio.

## Implementação

A IA apoiou a criação e refinamento do código em Next.js, TypeScript e Tailwind CSS.

Ela ajudou em:

- Organização dos dados em arrays.
- Criação de componentes reutilizáveis simples.
- Estruturação dos cards de projetos.
- Responsividade.
- Estados de botões desabilitados quando links estão vazios.

Decisão humana:

- Validar se o código continuava simples o suficiente para explicar em entrevista.
- Manter a stack definida.
- Não adicionar bibliotecas desnecessárias.

## Revisão

A IA foi usada para revisar clareza, consistência e possíveis problemas de implementação.

Foram observados:

- Legibilidade.
- Responsividade.
- Organização dos componentes.
- Coerência entre copy, projeto e objetivo profissional.

Decisão humana:

- Ajustar o tom para ficar profissional e honesto.
- Manter o perfil como júnior produtivo com IA.
- Evitar exageros ou promessas acima do nível atual.

## Testes

Os testes desta versão são manuais e automatizados por comandos locais:

```bash
npm run lint
npm run build
```

Também foi feita verificação visual em navegador local para confirmar que a página abre e que as seções principais aparecem corretamente.

## Documentação

A IA foi usada para estruturar este README e este documento de workflow.

Decisão humana:

- Documentar não apenas o resultado, mas também o processo.
- Explicar limites, responsabilidades e próximos passos.

## Limitações

Esta versão ainda não possui:

- Links reais de contato.
- Projetos publicados.
- Imagens ou demonstrações dos projetos.
- Testes automatizados de interface.
- Domínio próprio.

## Decisões Humanas

Mesmo usando IA em várias etapas, as principais decisões continuam humanas:

- Definir o objetivo profissional do portfólio.
- Escolher o que entra ou não na página.
- Validar se a copy está honesta.
- Testar se o site funciona.
- Revisar se a solução resolve o problema real.

Resumo do método:

> IA acelera o processo, mas eu valido, testo, ajusto e tomo as decisões.
